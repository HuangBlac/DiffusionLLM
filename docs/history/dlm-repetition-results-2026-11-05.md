# DLM200重复生成诊断结果

已完成80条固定权重采样、8组上下文轨迹、训练/开发各32段落的五种遮盖诊断。没有更新模型参数，原DLM200未修改。全部结果已从Colab外读回，原始JSON为751,368字节，SHA-256=`0ecee88757eb3e3ed3bafc6a7925c107227ec11eeede0fc9c08d54b8061dca61`。

**结论：已测条件下，贪心选择是机械重复的直接放大器；批量揭示与它存在交互，但逐词元贪心仍会循环短语。随机抽样大幅降低重复，却没有恢复稳定、连贯、可信的续写。因此不能把问题只归为采样，也不能直接认定再训更多步就会解决。**

## 对照范围

同一DLM200、同一组8个已观察的开发前文（来自5篇文章）、64格画布、相同合法token/EOS规则。所有新结果统一CPU FP32。随机/置信度顺序×每轮1/8token，temperature=1、解码种子101/202；另做置信度优先的贪心1/8token。先在每个提示词内平均解码种子，再平均提示词；不将16个输出当成16个独立训练重复。

种子在每条提示词上重置，会产生共同随机模式；本报告不据这些样本计算独立性或显著性结论。没有人工校准质量分数或DeepSeek评分。文本判断来自AI辅助逐条查看80个输出。CPU耗时不作为速度优势证据，P2准备曾短暂共享资源。

## 机械重复

重复率只计算首EOS之前的已交付token。本轮80条均非空、长度均不少于8；程序仍单独保存短输出与未定义比率的分母。

| 设置 | 相邻相同token | 重复4-gram |
| --- | ---: | ---: |
| 置信度贪心，每轮8token（G8） | 58.47% | 37.35% |
| 置信度贪心，每轮1token（G1） | 28.02% | 50.00% |
| 置信度抽样，每轮8token（C8） | 3.78% | 0.00% |
| 置信度抽样，每轮1token（C1） | 1.81% | 1.15% |
| 随机顺序抽样，每轮8token（R8） | 3.14% | 0.00% |
| 随机顺序抽样，每轮1token（R1） | 2.67% | 0.00% |

同权重G8→C8的相邻重复减少54.69个百分点，G1→C1减少26.21个百分点。单纯减小揭示数量并未消除重复：G1的相邻卡词减少，但长短语循环使重复4-gram高于G8。不能说每轮1token在所有重复指标上都更好。

随机抽样没有通过“空输出”制造低重复，但不少文本变成断裂句、拼接名称与不受支持的细节。C1有些样例能形成较完整句子，仍有明显事实和衔接问题；不能把低重复率解释为质量恢复。历史原始AR的同题输出也存在重复和事实不稳，不是完美参照；其设备/精度/耗时未混入本矩阵。

## 上下文反馈

随机逐位置生成中，在相同已揭示位置复制状态：一份保留生成词，另一份只把这些位置替换为参考原词；剩余位置、掩码及预测目标完全相同。参考条件不会回写生成过程，也不算正常生成成绩。

为避免短参考尾部使样本组成改变，下表只比较在16/32/48三个位置都有探针的同5条前文：

| 已揭示位置数 | 生成上下文CE | 参考上下文CE | 差值 |
| --- | ---: | ---: | ---: |
| 16 | 8.086 | 5.236 | 2.850 |
| 32 | 9.478 | 4.368 | 5.111 |
| 48 | 10.744 | 3.353 | 7.391 |

每个步数内部两条件预测完全相同的剩余位置；16/32/48之间的剩余目标集合会变化，即使提示词集合相同，趋势也只是描述性结果。这些配对结果支持生成上下文参与后续退化。参考词优势也包含合理续文偏离原文的效应，不能单独称为暴露偏差的因果证明，更不能分配“训练占多少、采样占多少”的比例。完整分母为16位置8条、32位置6条、48位置5条，均保留在结果JSON中。

## 模型能力与训练覆盖

新CPU结果的训练/开发去噪CE（表中概率为设定值，实际每次遮盖token比例有随机波动）：

| 遮盖率 | 训练32条 | 开发32条 |
| --- | ---: | ---: |
| 25% | 2.277 | 3.293 |
| 50% | 3.552 | 4.609 |
| 75% | 4.411 | 5.441 |
| 90% | 5.168 | 6.353 |
| 100% | 5.744 | 6.922 |

模型存在泛化差距，高遮盖仍弱。单时点训练/开发差距不足以判定后期过拟合；原20→200的固定32条GPU去噪指标仍总体改善。新实验重新排序了段落，因此除全遮盖外不能把掩码逐词视为与旧报告完全相同。全遮盖CPU6.922与旧GPU6.907接近，也不应归为新的训练改善或恶化。

确定性重构3200次训练抽样，与200条历史的输入/目标/监督token计数全部匹配：93次全遮盖、10次非零且不超过5%遮盖。长度128的805次抽样仅6次全遮盖。它们不是保存的逐token掩码，也不是经1/(L*p)加权后的学习贡献。它们提示生成起点/末端覆盖值得检查，不证明增加训练即可修复。
