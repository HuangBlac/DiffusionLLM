# 512 步学习运行与 DLM512 固定权重诊断

证据截至 2026-11-08；[机器可读聚合快照](../../results/project-summary.json)与本文为本地公开部分的结果整理，不含原始文本、账户信息或检查点定位。数据从私人学习报告、逐检查点评价 JSON、固定权重诊断 JSON 和阶段总报告核对；具体原始数据与执行回执仍保留在私有目录。

## 对象、配置与方法

AR 与掩码去噪 DLM 从同一 Qwen2.5-0.5B Base 基座独立开始，seed 11，全参数各更新 512 次；训练集 4096 条、开发集 100 条，前文上限 128 token，续文容量 128 token，DLM 固定画布为 128 格。两组相同样本索引序列、有效 batch 16；DLM 的结束后 MASK 后缀可见且不监督。设置与评价协议见[学习运行规格](../current/learning-run-plan-2026-11-06.md)。

四个固定开发评价点为基线 0 和 128、256、512 步。AR 指标是续文条件 NLL；DLM 指标是 50% 或 100% 遮盖目标的交叉熵（CE）及 Top-1 原词恢复准确率。损失单位为 nats/token，两类目标与条件信息不同，不横向比较数值。

| 更新步 | AR NLL | DLM 50% CE | DLM 50% Top-1 | DLM 100% CE | DLM 100% Top-1 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 2.8295 | 17.5459 | 0.59% | 19.9684 | 0.05% |
| 128 | 2.4541 | 4.3139 | 28.00% | 6.6669 | 3.05% |
| 256 | 2.5587 | 4.0747 | 30.84% | 6.6970 | 2.82% |
| 512 | 2.7065 | 3.8435 | 34.53% | 6.5955 | 4.08% |

Top-1 是全部被遮盖参考目标 token 上的正确预测数除以目标数，包含被遮盖的自然 EOS，不含无监督 MASK 后缀；它不衡量自由生成的句子成功率。四个检查点均使用同一批 100 条开发例及固定遮盖种子：50% 条件实际计入 3,064 个目标，100% 条件计入 5,959 个目标。准确率按这些 token 微平均，未对各条样本准确率再取宏平均。数值核自私人学习报告的逐检查点 `dlm-evaluation-*.json` 中 `metrics.rates[rate].accuracy`；聚合规则见[开发评价实现](../../experiments/learning_run_evaluation.py)。本次补录为既有结果的展示整理，没有重新运行模型。

四个测量点中，AR 在 128 步最低，之后回升；DLM 50% 遮盖 CE 持续下降，100% 遮盖 CE 在 128 步后变化较小。它们是开发评价点，不是逐步训练损失。

## 固定权重诊断

对 DLM512 冻结权重进行 CPU FP32 推理，不进行训练；参数原位版本检查未发现变化。从训练与开发集分别按内容哈希选取 32 条，在五种固定遮盖率下评价。CE 按实际被遮盖的参考目标 token 数加权；两个数据集的样本不逐条配对。

| 设定遮盖率 | 训练 CE | 开发 CE |
| ---: | ---: | ---: |
| 25% | 2.3276 | 2.4155 |
| 50% | 3.4886 | 3.8099 |
| 75% | 4.6016 | 4.9257 |
| 90% | 5.3773 | 5.7326 |
| 100% | 6.1465 | 6.4584 |

配对上下文探针对 8 条固定开发提示，在 128 格画布中按随机顺序逐位置揭示，温度为 1；在 16、32、48 次揭示后，将生成上下文与已揭示且存在参考目标的位置替换为参考 token 的上下文比较。两分支在其余位置、注意力、遮盖状态和剩余参考目标上保持一致。下表是生成 CE 减去参考替换 CE，以各提示剩余目标 token 数加权；每个时间点都是 8/8 提示为正。

| 已揭示位置 | 剩余参考目标数 | CE 差 | 正差提示 |
| ---: | ---: | ---: | ---: |
| 16 | 515 | 1.7245 | 8/8 |
| 32 | 448 | 2.8490 | 8/8 |
| 48 | 381 | 3.6727 | 8/8 |

高遮盖困难和生成上下文条件差异同时存在，不能分配因果占比。各揭示点的剩余目标不同，跨点趋势仅作描述；逐位置揭示也不同于主实验 32 轮去噪轨迹。参考替换差异可能同时涉及生成误差、合理分支偏离、参考信息及 EOS 暴露。训练与开发遮盖诊断样本有限，不能推出总体效果。历史 P1 使用不同画布条件，CE 不作跨实验收益比较。

## 恢复与结论范围

AR512 与 DLM512 最终检查点均独立下载、在 CPU 恢复，并通过有限值推理检查；模型、优化器以及 CPU/抽样随机状态完成恢复核验。CUDA 随机状态已保存，未进行 GPU 状态重放。终点生成有残句、重复和提前结束；8 条提示不能建立一般生成质量或等质量速度优势。该学习运行采用固定后缀政策，与独立 P2 成对政策试验分开：截至现有日期化接续证据，P2 无已验证参数更新或检查点。

## JSON 字段

`prepared_on` 为聚合材料整理日期；离线重建保留此日期，与 `evidence_as_of` 的实验截止日分开。

`schema_version` 为格式版本；`evidence_as_of` 为证据截止日；`title` 为标题。`scope` 描述模型、训练种子、样本数、token 容量、每组更新次数、训练模式和限制；`canvas_tokens` 指 DLM 续文画布容量。`learning_curve` 的每行对应一个固定开发评价点，三个损失均为 nats/token。`mask_diagnosis` 的 `mask_rate` 是设定比例，`train_ce` 与 `dev_ce` 为实际遮盖目标加权 CE。`context_probe` 的 `revealed_tokens` 指揭示的画布位置数，差值为剩余参考目标 token 加权 CE 差，正差提示数和总提示数用于表示配对方向。差值按原诊断报告保留四位小数；其他 CE 在 JSON 中保留原始聚合精度。`milestones` 记录各项独立状态；`sources` 仅列仓库相对路径。详细过程与当下接续入口见[项目进度](../progress.md)。
