| 项目 | 规格 |

| DLM输入 | BOS＋128前文＋128续文容量；固定MASK后缀可见，后缀不参与loss；真实续文和自然EOS按既有shift目标监督 |

| 数据曝光 | 两组同种子11、同样本索引序列；effective batch16（micro2×累积8） |

启动前仅用独立短测测吞吐、显存、保存耗时，随后丢弃短测权重并重设随机状态。若预算装不下512步，不启动完整运行；不能看过质量结果后悄悄减少更新量并宣布本批完成。

## 3. 固定、有限的评价

- 0/128/256/512：100开发例，AR报告续文NLL；DLM报告固定0.5和1.0遮盖条件下的masked CE。统一样本、目标位置、噪声种子和DLM画布条件，不把AR NLL与DLM masked CE当相同似然横比。
- 按哈希固定选开发集8条前文。各检查点只运行一个固定DLM配置（128容量、32前向、T=1、seed101），并保留完整输出，不挑选好样例。
- 仅终点评价展开：DLM前向数16/32/128，greedy与T=1；随机设置固定seed101/102。AR基座与继续训练AR用同前文、相同输出上限，启用正常KV cache；原始AR基线无需在每个训练点重复计时。
- 报告实际生成token数、自然EOS、空/短输出、相邻及4-gram重复、整段耗时、前向数和样例。加载/预热与生成时间分开；固定长度上限不等于质量相同。
- 本批是开发性学习结果。8条前文不支持一般质量结论；不把低重复当连贯，不宣布速度优势。付费裁判、MAUVE、新基准和人工校准不是首份报告前置；需要正式质量主张时再完成相应评估。
