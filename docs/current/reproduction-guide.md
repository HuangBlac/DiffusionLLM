## Markdown 排版与发布验收

1. 行内公式使用 `$...$`。独立公式使用各占一行的 `$$`，块前后留空行。公式内容使用 LaTeX 语法。
2. 中文标点之后的行内公式在起始 `$` 前留空格。集合花括号优先使用 `\lbrace`、`\rbrace`。将独立等号与相邻公式内容放在同一行，保持段落结构。
3. 正文中中文与英文、数字之间加半角空格，如 `512 步`、`8/8 提示`；数字与单位之间留空格，如 `5.93 GB`；数字与百分号紧贴，如 `95%`。保留模型名称内部拼写、代码、路径、URL、公式和生成样例原文。
4. 标题、列表、公式块与前后正文之间留空行；代码围栏成对闭合并注明语言。文档与图片链接使用仓库相对路径或目标平台可访问的地址。
5. 先核对公式含义、表格数值、样例原文和链接目标，再检查 GitHub 实际页面的公式、标题、列表、表格与图像。需要 PDF 时另行检查导出成品。
6. 发布前读取目标分支最新提交，逐文件审查差异；发布后读回文件内容并检查页面。源码检查、生成器测试和页面验收分别记录。
